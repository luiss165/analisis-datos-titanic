# \# Análisis de datos del Titanic

# 

# \## Descripción

# 

# Este proyecto realiza un análisis y preprocesamiento de datos utilizando el dataset Titanic de Kaggle.

# 

# \## Objetivo

# 

# Explorar los datos de los pasajeros del Titanic, identificar información faltante y realizar procesos básicos de limpieza y análisis.

# 

# \## Herramientas

# 

# \- Python

# \- Pandas

# \- NumPy

# \- Matplotlib

# \- Seaborn

# 

# \## Estructura del proyecto

# 

# \- `data/`: contiene los datos del proyecto.

# \- `notebooks/`: contiene los notebooks de análisis.

# \- `src/`: contiene el código fuente.

# \- `requirements.txt`: contiene las dependencias del proyecto.
